# Viewclaude-data

Просмотрщик выгрузки диалогов Claude (Settings → Privacy → Export data).

`viewer.html` — одностраничное приложение для телефона и компьютера:

- открывает zip из письма Anthropic или `conversations.json` (можно несколько частей сразу);
- файл разбирается прямо в браузере, никуда не отправляется и запоминается на устройстве (IndexedDB);
- поиск по названиям и тексту, фильтр «с текстом / удалённые / все»;
- markdown, подсветка кода, свёрнутые шаги работы (поиск, команды), копирование сообщений и целого диалога.

Файл написан под Claude Artifacts: в нём нет `<!doctype>`, `<html>` и `<body>`, их добавляет платформа.

Сами выгрузки в репозиторий не добавляются (см. `.gitignore`).
